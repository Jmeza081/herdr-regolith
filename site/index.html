02 · Knobs

What a layout can change

Each control maps to one key in a layout file. The key is printed under its label, and the files in section 06 update as you move them.

Terminal text root

font_size
terminal_line_height · 0.8–2

Pane frames tab block · pane

radius
gap
terminal_padding [x, y]

Pane header pane.header

The header is the shipped pane mod: one copy per pane, reading title, folder, branch and agent status. On hover it draws over the terminal, so the terminal never resizes.

Glass root

terminal_opacity · 0–1

With blur on, Herdr wants a transparent canvas and a translucent chrome. The export writes those overrides for you. The red horizon here stands in for your desktop.

03 · Slots

Every color Herdr names

A theme sets these by name, and mods read them through theme(), so every panel follows along. Hover a slot to outline it in the window above.

Terminal palette ansi 0–15

  • Terminalsbackground, foreground, cursor, selection and the 16 ANSI colors. These are the only required keys in a theme file.
  • PanelsHerdr derives chrome, surface, border and the rest from the terminal colors. Set them under colors to take control.
  • Agent statusworking, blocked, done, idle, unknown color the dots in the sidebar, pane headers and toasts.
  • Regolith ruleOne red per screen. Here it marks the focused pane and the one action that needs you.

05 · Install

Install in two steps

The script copies the six theme files into ~/.config/herdr-app/themes/ and touches nothing else. Run it again any time to update.

1
Add the themes 
curl -fsSL https://raw.githubusercontent.com/Jmeza081/herdr-regolith/main/install.sh | sh

Or download any file from the gallery and put it in ~/.config/herdr-app/themes/. Herdr picks new themes up without a restart.

2
Pick one

Open Settings with ⌘,, choose Look, and click a theme under Dark, and one under Light if you like. Set Appearance to System to follow macOS.

herdr-app do app.theme --name regolith

The command does the same from a terminal, for the layout you're in.

×
Uninstall

Delete the six files from ~/.config/herdr-app/themes/, then pick another theme in Settings.

The themes
Six palettes, one family
Each sets the terminal colors and every panel color Herdr has. All six come with both installs, so you can change your mind any time.

    

  






  

    
The full look
What Regolith Glass changes
The themes set colors. The full look also reshapes a few of Herdr's panels to match.

    

      
A Remote badge
Claude Code panes with Remote Control on get a small dish, so you know which ones your phone can reach.

      
A dot that breathes
Working agents get a slow green pulse in place of a spinning ring, everywhere.

      
A moon for every space
Spaces get a moon phase on the theme's red, instead of a letter.

      
A calmer agents list
Status first, then the name and the AI, regolith | Claude, and a word for what it's doing.

      
Space-age icons
A telescope for search, an orbit for settings, a planted flag for pins. Program icons turn one color.

      
No focus ring
The pane you're in doesn't get a red outline. Its header tells you instead.

    

  






  

    
Questions
Before you install

    

      
What does the installer touch?
Only ~/.config/herdr-app. The themes go in themes/. The full look adds one layout, seven panels, and a programs.json for one-color program icons. If you already have a programs.json, it's left alone.

      
How do I undo it?
Switch Herdr back to its own layout and a stock theme in Settings, then remove the files:


cd ~/.config/herdr-app
rm themes/regolith*.json themes/mono.json themes/paper-cobalt.json
rm layouts/regolith-glass.json
rm -r mods/regolith-*

      
Will it keep up with Herdr updates?
The themes will. The full look uses copies of seven Herdr panels, and copies don't get Herdr's updates on their own. Run the installer again after this project updates. If an update ever breaks something, switch to Herdr's own layout; the themes keep working there.

      
Can I change the fonts or corners?
Yes. The customizer lets you turn the knobs on a live window and copy the settings for your own copy of the layout.

      
Can I use the themes with my own layout?
Yes. Pick "Just the themes" above, then choose one in Settings, ⌘ , › Look. They work in every Herdr layout.
